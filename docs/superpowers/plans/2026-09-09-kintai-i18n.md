# Kintai i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every user-facing string in both Kintai bundles renders in English or Japanese, one language per screen, chosen by the browser on first open and by a saved per-person toggle after.

**Architecture:** A typed dictionary (`en` is the key source, `ja satisfies` it) read through a React provider; a `language` field on `KintaiIdentity` and a `setLanguage` write on both facets, backed by two additive store tables; a header toggle with Phosphor's `Translate` glyph. Screens migrate file by file, tests pin one language each, and a stray-literal scan guards the result.

**Tech Stack:** TypeScript, Cloudflare Workers + Durable Objects (SQLite), Cap'n Web + `@validateRpc()`, React single-file bundles, vitest (workers pool + jsdom), `@phosphor-icons/react`.

**Spec:** `docs/superpowers/specs/2026-09-09-kintai-i18n-design.md` — read it first.

## Global Constraints

- **Identity from the capability.** `setLanguage` takes a language, never an account or employee id.
- **Lookup table, not CHECK** for the language set; seed from `UI_LANGUAGES` in `src/types.ts` so type and seed are one list.
- **One language per screen.** No bilingual labels survive. Dates `YYYY-MM-DD`, clocks `HH:MM` in both; durations/ages translated.
- **Keys by meaning, not by English text.** `en` is the source of truth; `ja` is `satisfies Messages`.
- **Every copy-producing helper takes `t`.** No helper returns hard-coded prose.
- **Sandbox:** `type="button"`, no `<form>`; the iframe has NO storage — never touch localStorage.
- **Tests render one explicit language.** Fakes default `language: "ja"`; English assertions set `"en"`.
- **Bundles committed minified** (`node build-app.mjs`, three builds, last two identical; the owner's dev server may be running — it does not disturb the build, but a running `--watch` can rewrite the .txt files unminified: restore with `git checkout` before committing). Never commit a 24k-line bundle.
- **No worktree; commit incrementally; per-test DOs; departmented test routes.** Baseline entering: **540 worker / 148 app** at `c05d6bb`. Gates every task: `pnpm exec vitest run`, `pnpm exec vitest run -c vitest.app.config.ts`, `pnpm exec tsc --noEmit`, `pnpm run typecheck:app`; RPC-touching tasks also `pnpm exec capnweb-validate build --out .wrangler/validate`.
